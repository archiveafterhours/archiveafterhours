# Notes from the Archive

I collect fragments of old catalogues, auction records, and private collections. Some histories are incomplete; others have been carefully rearranged.

My notes are scattered across places, but I keep one index for the records worth revisiting.

Somewhere between old books and afternoon tea, I learned that the index is often more useful than the story.

**Research index:** [The Collector's Index](https://shreelakaudiki.github.io/lost-collector-index/)

*Not every record tells the truth. Sometimes the gaps matter more.*
